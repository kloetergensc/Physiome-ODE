The datasets

Fifty ODE models picked from the Physiome Model Repository for how varied their dynamics are. Pick one and sample instances the way the benchmark builds them.

observed to forecast forecast window

Each click draws one of the first 12 instances of the dataset, regenerated with the benchmark's seeds and solver settings, then applies a fresh noise draw (σ = 0.05 on z-scored values) and keeps each value with probability 0.2, as in the benchmark. Channels are ordered by their JGD score.

Each Physiome model is a set of coupled ODEs, often written for one paper about one cell type or organ. We simulate many trajectories per model, varying the initial states and the model constants, then turn them into an irregular forecasting task.

JGD (joint gradient deviation) scores how much a channel's increments vary along each trajectory and across trajectories, averaged over the ten highest-scoring channels. High JGD means varied, fast-changing dynamics. Low, medium and high below are thirds of the 50 datasets by JGD.

How models are scored

Four aggregates, each computed over the datasets in the current slice. They answer different questions, so the table shows all of them.

Elo

Each dataset is one match between every pair of models; lower mean MSE wins. A Bradley–Terry model turns the matches into ratings on the chess scale.

P(i beats j) = 1 / (1 + 10^((E_j − E_i) / 400))

Average rank

Rank 1 is the lowest mean MSE on a dataset. Tied models share the better rank, as in the paper.

rank(i) = mean_d rank_d(i)

Wins

Datasets on which the model has the lowest mean MSE. Ties count for every tied model, so wins can add up to more than the dataset count.

wins(i) = #{ d : MSE_d(i) = min_j MSE_d(j) }

Improvability

How much lower the best model's error is, on average. A model at 0% is the best on every dataset in the slice.

imp(i) = mean_d (MSE_d(i) − MSE*_d) / MSE_d(i)

Every model is trained separately on each dataset and fold, with early stopping on a validation split. The reported number is test MSE on z-normalized values, averaged over five folds.

Add your model

The leaderboard takes new published models from the community. A submission is code plus results; maintainers rerun part of it before it counts as verified.

  1. Implement

    Add the model under experiments/training/models/ with a collate function that maps our IMTS format to your input format, plus a train_<model>.py script.

  2. Run all 50 datasets

    Train five folds per dataset with the standard split.

    python train_<model>.py -dset dupont_1991b --fold 0

  3. Open a pull request

    Include the code, your hyperparameters, an entry in website/models.json, and website/results/<model>.csv with a row per dataset and fold.
